隐私政策

生效日期：2026 年 11 月 12 日

XDRemux 在你的设备上本地转换照片。我们不收集、不上传、不出售任何个人数据，应用里没有账号、广告、统计分析或第三方追踪。

适用范围

本政策适用于 XDRemux 的各个版本：iOS、iPadOS 与 macOS 上的原生版（包括通过 TestFlight 分发的测试版），Windows、macOS、Android、iOS、Linux 上的跨平台版，HarmonyOS 原生版，以及本网站 xdremux.app。

照片与文件

  • 识别、预览、转换全部在设备本地完成，照片和视频不会发送到我们或任何第三方的服务器。
  • 导入的副本、转换结果、队列记录和设置保存在应用自己的存储空间或你选择的文件夹里；卸载应用或在应用内清除即可删除。
  • 照片里的拍摄信息（如时间、机型、位置等 EXIF）只在本地读取，用于显示和写入转换后的文件。

应用会请求的权限

  • 照片：用于从相册选取要转换的照片，以及把转换结果存入相册。
  • 文件与文件夹：仅访问你主动选择、拖入或通过分享面板交给应用的文件。
  • 本地网络：仅用于“局域网互传”，在同一网络内发现设备并直接传输文件。
  • 通知（部分版本）：用于提示后台转换的进度与结果。

这些权限都可以在系统设置里随时关闭，关闭后对应功能不可用，其余功能不受影响。

局域网互传

互传基于 LocalSend 协议，文件在同一局域网内的两台设备之间直接传输，不经过我们的服务器或任何互联网中转。为了让对方看到并选择你的设备，应用会在局域网内广播你设置的设备名、设备类型和端口；传输内容使用 HTTPS 加密。不使用互传功能时不会进行这些通信。

联网行为

  • 原生版（iOS / iPadOS / macOS）：除局域网互传外不发起任何网络连接。
  • 其他版本：可能访问 GitHub 的公开接口检查是否有新版本。这是一个不带任何个人信息或设备标识的普通请求；和访问任何网站一样，GitHub 会看到你的 IP 地址，并按其自身的隐私政策处理。

TestFlight 与应用商店

通过 TestFlight 或应用商店安装时，平台方（如 Apple）可能按其自身政策收集崩溃日志和使用数据，并在你同意的情况下把经匿名处理的诊断信息提供给开发者。你在 TestFlight 里主动提交的反馈（截图和文字）会发送给我们，只用于修复问题。

本网站

xdremux.app 是静态网站，不使用 Cookie，也没有统计或广告脚本。网站由 Cloudflare 和 GitHub Pages 提供服务，首页会从 Google Fonts 加载字体，并请求 GitHub 的公开接口获取最新版本号；这些服务商会按各自的隐私政策处理访问日志（如 IP 地址）。下载链接指向 GitHub Releases。

儿童隐私

XDRemux 不面向儿童收集信息；应用本身也不收集任何人的个人数据。

政策变更

如果应用的数据处理方式发生变化，我们会更新本页并修改生效日期。本页的历史版本可以在网站仓库的提交记录里查看。

联系我们

对本政策有疑问，请在 GitHub Issues 提出。XDRemux 是开源项目，你也可以直接查阅源代码核实上述内容。

Privacy Policy

Effective 12 November 2026

XDRemux converts photos locally on your device. We do not collect, upload or sell any personal data. The app has no accounts, ads, analytics or third-party tracking.

Scope

This policy covers every edition of XDRemux: the native app for iOS, iPadOS and macOS (including builds distributed through TestFlight), the cross-platform app for Windows, macOS, Android, iOS and Linux, the native HarmonyOS app, and this website, xdremux.app.

Photos and files

  • Detection, preview and conversion all run on your device. Your photos and videos are never sent to us or to any third-party server.
  • Imported copies, converted files, the queue and your settings are stored in the app's own storage or in a folder you choose. Uninstalling the app, or clearing them inside the app, deletes them.
  • Photo metadata such as capture time, device model and location (EXIF) is read locally only, to display it and to write it into the converted file.

Permissions the app asks for

  • Photos: to pick photos to convert and to save converted photos to your library.
  • Files and folders: only the files you select, drop in, or hand to the app from the share sheet.
  • Local network: only for local transfer, to discover devices on the same network and send files directly to them.
  • Notifications (some editions): to report the progress and result of background conversions.

You can turn any of these off in system settings at any time. The related feature stops working; everything else keeps working.

Local network transfer

Transfer uses the LocalSend protocol. Files travel directly between two devices on the same local network and never pass through our servers or any internet relay. So that the other device can see and choose yours, the app announces the device name you set, the device type and a port on the local network. Transfers are encrypted with HTTPS. None of this happens unless you use the transfer feature.

Network access

  • Native app (iOS / iPadOS / macOS): makes no network connections other than local transfer.
  • Other editions: may contact GitHub's public API to check for a newer version. The request carries no personal information or device identifier. As with any website, GitHub sees your IP address and handles it under its own privacy policy.

TestFlight and app stores

When you install through TestFlight or an app store, the platform operator (such as Apple) may collect crash logs and usage data under its own policies and, with your consent, share anonymised diagnostics with the developer. Feedback you choose to send through TestFlight (screenshots and text) reaches us and is used only to fix problems.

This website

xdremux.app is a static site. It sets no cookies and runs no analytics or advertising scripts. It is served by Cloudflare and GitHub Pages; the home page loads fonts from Google Fonts and asks GitHub's public API for the latest version number. Those providers process access logs, such as IP addresses, under their own privacy policies. Download links point to GitHub Releases.

Children

XDRemux does not knowingly collect information from children. The app does not collect personal data from anyone.

Changes

If the way the app handles data changes, we will update this page and its effective date. Earlier versions are visible in the site repository's history.

Contact

Questions about this policy can be raised on GitHub Issues. XDRemux is open source, so you can also check the source code to verify what is described here.
