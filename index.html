往返工作流

一帧影像，
动用两台手机。

用 OPPO 拍摄，在 iPhone 上编辑，再把照片带回 OPPO。XDRemux 在两端之间转换，并把原机信息恢复回去。

  1. 第 1 步

    生成编辑副本。保留 OPPO 原始照片，生成一份 Apple 照片编辑副本。

  2. 第 2 步

    在 iPhone 上调整。把副本发送到 iPhone，在 Apple 照片里调整摄影风格或人像效果。

  3. 第 3 步

    回传并配对原图。把编辑后的照片传回 XDRemux，与原始照片配对。

  4. 第 4 步

    恢复并导出。按需恢复原机水印、OPPO 元数据和私有尾部数据，再选择输出模式。

原图是恢复信息的依据，请不要只保留编辑副本。9

从导入到导出。

转换队列是主要入口。手机上是紧凑队列和底部操作栏，电脑上有更宽的队列与详情布局。

支持原生拖放，HEIC 队列预览使用系统 WIC。截图来自 0.3 版本。

  1. 1

    添加照片

    用系统选择器导入 HEIC、HEIF 或 JPEG，也可以分享或拖放添加。

  2. 2

    查看详情

    检查格式、尺寸、EXIF、HDR 类型、拍摄模式与动态照片信息。

  3. 3

    选择转换方式

    选择输出模式，按需开启摄影风格、人像或动态照片处理。

  4. 4

    开始转换

    在队列里查看进度。失败项目可以重试，或调整设置后重新转换。

  5. 5

    导出结果

    电脑上写入输出目录；iPhone 上可直接保存为 Live Photo，其他手机保存静帧到图库或分享文件。

Linux 桌面为 x64 预览版；Windows ARM64 安装包仍为实验性，暂不提供。 全部版本 › 鸿蒙原生版说明 ›
  1. iOS 与 HarmonyOS 安装包未签名，不能像商店应用一样直接安装。iOS 版未通过 App Store / TestFlight 分发；HarmonyOS 请通过 DevEco Studio 配置本地签名。macOS 版未经 Apple 公证，首次打开会被 Gatekeeper 拦截，请在「系统设置 › 隐私与安全性」中允许，或右键点按 app 选择「打开」；目前仅支持 Apple Silicon（M 系列），Intel Mac 可以启动但无法完成转换。iOS 最低支持 iOS 15.0；Android 仅提供 arm64 安装包（最低 API 24）；Linux 为 x64 预览版，需要 glibc 2.35 及以上，系统托盘与完成通知暂未接入。
  2. ProXDR 转换支持 LHDR / UHDR 容器。选择器接受 HEIC / HEIF / JPEG，但扩展名正确不代表能完成所有转换，能力取决于照片内部结构。纯 Rust 解码暂不支持 4:2:2 / 4:4:4 HEVC，部分 iPhone HEIC 截图可能失败。转换失败时，可在应用内的编解码诊断中查看当前平台的解码能力与失败原因，并复制诊断信息。带 P3 / sRGB 等 RGB ICC 的 JPEG 会在 HEIC 主图与主体瓦片中保留源色彩配置，CMYK / 灰阶等不支持的 ICC 会明确报错；部分小米 / 红米 Ultra HDR JPG 在 ISO 元数据版本不受支持时会回退到 Adobe HDR XMP，照片详情会注明「HDR 解析失败」的原因。
  3. HDR 能否显示、图库是否允许继续编辑，取决于目标应用与设备。OPPO 图库对兼容文件再次编辑后，HDR 增益图仍可能丢失。本页照片与界面效果为示意图，并非实拍或实际输出。
  4. Apple 摄影风格、人像及 Live Photo 包含实验性实现，实际效果取决于原始照片结构、系统版本和目标设备。请保留原图，先用少量照片验证自己的工作流。
  5. OPPO ProXDR 走 HDR 转换路径；其他普通照片走风格重建路径，输出 SDR + 风格，不保证保留原有增益图。普通照片的语义分区蒙版仍含占位实现，柔肤效果尚未完整实现；部分非 Standard 风格的调节参数尚未支持，效果不承诺与 Apple 原生逐像素一致。
  6. 人像转换只使用照片中真实存在且可读取的深度信息，不会从普通照片生成景深。人像效果通常需要在 Apple 照片中手动开启。缺少可用 src.image 时回退到 OPPO 主图，缺少受支持的深度数据则跳过人像转换。OPPO 前置人像与华为支持均以现有样片为依据，不代表所有机型与拍摄模式都已适配。
  7. Live Photo 由同名 HEIC 与 MOV 两个文件组成。iOS 版可在应用内直接保存，两个文件以同一事务写入「照片」，成为可播放、有声音的实况照片；在电脑或其他设备上，请把 HEIC 和 MOV 一起导入 Apple 照片。Android 与 HarmonyOS 的「保存图库」只处理静帧，HarmonyOS Flutter 版暂不支持成对分享两个文件。支持 Android V1 / legacy MicroVideo、HEIF mpvd、OPPO LPEX 与已验证的华为追加视频结构。
  8. 华为照片的识别、风格、人像与动态照片处理共用 Rust 管线，但共用逻辑不等于所有设备都已完成真机验收。XMAGE xtstyle 目前用于只读诊断，尚未映射到 Apple 摄影风格。
  9. 往返工作流依靠原始照片恢复原机水印、OPPO 元数据和私有尾部数据。恢复原机水印为可选项，不勾选时保留 iPhone 回传画面。

尽量导入未经社交软件压缩或图库重编码的原文件，私有尾部、深度或动态资源可能在转存时丢失。设备兼容性按样片逐步验证，已有样片通过不代表整个平台或品牌都已适配，详见设备兼容矩阵。

反馈问题时，请在 GitHub Issues 附上平台、设备型号、系统与应用版本、转换选项、错误信息（可从应用内的编解码诊断复制）和可复现的原始样片。照片可能包含位置等隐私信息，分享前请确认授权范围。
